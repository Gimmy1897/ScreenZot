# ScreenZot

ScreenZot is a Zotero 7+ plugin for capturing areas of PDFs in the built-in reader. Start a capture from the reader toolbar, the PDF context menu, or with `Ctrl/Cmd+Shift+S`.

Choose a rectangular, elliptical, polygonal, or freehand selection, then copy it to the clipboard, save it as a PNG, or add it to a new Zotero note.
